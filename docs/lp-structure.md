# LP Structure

## ページ順序

1. Header：告知、ロゴ、ページ内ナビ、CTA
2. First View：中心価値、補足コピー、CTA
3. Voice：受講生の声4件
4. Middle CTA：悩みの提示、解決メッセージ、CTA
5. Point：支援の特徴3件
6. Content：プログラム内容6件
7. Vision：方針と目指す変化
8. Profile：講師・運営者紹介
9. FAQ：よくある質問5件
10. Contact：問い合わせフォームの外観

## Interaction

- VoiceとContentはPC・スマホともに横方向へスライドできる。
- タッチ、マウス、トラックパッド、左右ボタン、左右矢印キーに対応する。
- 現在見えているカード範囲と総件数をスライド下に表示する。
- 自動再生と無限ループは使用しない。
- Voiceの再生アイコンは動画素材がない現段階では装飾として扱い、操作要素にはしない。
- CTAはContactへページ内移動する。
- FAQはネイティブの`details` / `summary`で開閉する。
- Contactはブラウザ内の入力検証と確認表示までとし、フォームを消さず、未送信であることを明記する。外部送信は行わない。
